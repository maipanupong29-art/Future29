# Hospital Automation

พื้นที่สำหรับสคริปต์และเอกสาร workflow งานโรงพยาบาล เช่น KPI รายงาน งานนัดหมาย และการตรวจความครบถ้วนของข้อมูล

## กฎข้อมูล

- ใช้ข้อมูลจำลองหรือข้อมูลที่ผ่านการทำให้ไม่ระบุตัวบุคคลแล้วเท่านั้น
- ห้ามใส่ secret, token, password หรือไฟล์ตั้งค่าจริง
- แยก `src/`, `docs/`, `config.example/` และ `tests/`
- ระบุแหล่งข้อมูล เงื่อนไข และผลลัพธ์ที่คาดหวังใน README ของแต่ละเครื่องมือ
