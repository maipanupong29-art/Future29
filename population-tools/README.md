# Population Tools

เครื่องมือสำหรับรวม ตรวจสอบ ทำความสะอาด และแปลงไฟล์ข้อมูลประชากร

## โครงสร้างแนะนำ

- `src/` โค้ด Python
- `templates/` แม่แบบเปล่า
- `docs/` วิธีใช้และกฎตรวจสอบข้อมูล
- `tests/` ชุดทดสอบด้วยข้อมูลจำลอง

> ห้ามเก็บชื่อ นามสกุล HN เลขบัตรประชาชน วันเกิดจริง หรือข้อมูลที่ระบุตัวบุคคลได้
