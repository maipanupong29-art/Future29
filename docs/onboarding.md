# Onboarding Guide

This document complements `README.md` and gives newcomers a practical first-week path.

## Day 1
- Clone repo and verify toolchain versions.
- Read `README.md` and `docs/architecture.md`.
- Run formatter/linter/test commands.

## Day 2-3
- Pick one small issue.
- Submit first PR with tests and docs update.

## Day 4-5
- Pair with a maintainer on one medium-size task.
- Learn release/deploy workflow and incident basics.

## Definition of Ready (for contributors)
- Environment setup complete.
- Can run tests locally.
- Understand branching + PR process.
- Knows where to ask for help.
